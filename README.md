# Sprint_7
Проведено тестирование API Яндекс.Самокат
Конфигурация среды. в которой проводилось тестирование:
- Java 11
- JUnit 4.3.12
- Rest Assured 5.5.5

Разработаны автотесты для тестирования следующего функционала:
1. Создание курьера
2. Логин курьера
3. Создание заказов
4. Список заказов

Сгенерирован отчет Allure

Для запуска тестов применять команду - mvn clean test
Для загрузки Allure отчета применять команду - mvn allure:serve
